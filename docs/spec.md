# Keypace spec

Keypace is a native macOS menu-bar app that measures real typing speed and
patterns in the background and keeps everything on this Mac.

## Platform

- macOS 15+, Swift 6, SwiftUI and Swift Charts, AppKit where SwiftUI falls short.
- Xcode project generated by XcodeGen from `project.yml`.
- All logic lives in the `KeypaceCore` Swift package, tested with `swift test`.
  The app target is UI and system glue only.
- Storage: SQLite through GRDB, one database file in Application Support.
- Permission: Input Monitoring only. No network access, no accounts.

## Privacy

- Never store typed text, an ordered keystroke log, window titles or URLs.
- Store only aggregates: sessions, per-key counts, key-pair timings,
  keyboards, layouts and app identifiers.
- No keystrokes are recorded while secure input is on (password fields).

## Features

1. Capture
   - Passive, listen-only keyboard event tap, plus IOHID device matching so
     each keystroke is tied to the physical keyboard it came from.
   - Context: frontmost app, input source (layout), keyboard, sleep/wake,
     secure input.
   - Listener pauses by macOS and unreadable key-downs are counted in local
     preferences, with the date counting began and the most recent occurrence.
     Presses during a pause can't be counted.
2. Sessions and metrics
   - A session ends after N seconds without a keystroke (default 5) or when
     the frontmost app, keyboard or layout changes.
   - Sessions shorter than the minimum size (default 25 characters) are not saved.
   - Typing time leaves out pauses: a gap counts when it's under 4× the median
     gap for that key pair, key or overall, clamped to 250 ms–3 s (600 ms before
     there's history). A burst's first keystroke gets one median gap.
   - WPM = characters that stayed ÷ 5 per minute of typing time; CPM; KPM.
     Historical speed metrics, including KPM, use saved sessions.
   - Keystrokes and per-key usage count every accepted key-down, including short
     bursts, shortcuts and navigation outside sessions. Held-key repeats,
     modifier-only presses, software-sent keys and excluded apps don't count.
     Counts are hourly by app, keyboard, layout and key; overlapping hours count
     in full. Sessions saved before this version keep their own character-key and
     Delete counts, included by session start. An immutable session-ID boundary
     recorded during migration separates them from new press counts, with no gap,
     double counting or backfill.
   - Deletions count only when they remove characters typed in the session;
     Option-Delete uses transient character categories to estimate the word;
     Command-Delete is editing and clears ownership because visual line wrapping
     is unknown. Corrections =
     deleted ÷ typed, labeled as corrections, not accuracy.
   - Held character keys count once; a held Delete counts every deletion.
   - Per-key corrections: each deleted character is charged to the key that
     typed it.
   - Live speed: events in the last 8 s, using the same pause-filtered typing time
     as saved sessions, cleared 2 s after typing stops.
3. Synthetic-input filter: keystrokes must come from the HID system event
   source with no posting process; strict mode also drops presses under 5 ms
   apart. Filtered presses are counted, not recorded as typing. Paste and AI
   autocomplete insert text without keystrokes, so they never count.
4. Menu-bar dropdown: the period's speed with its change against the previous
   period, live speed while typing, speed through the day, corrections, typing
   time and top apps. Footer: Open Keypace, Quit.
5. Overview: stat row (speed, corrections, typing time, keystrokes, streak)
   with period-over-period change, speed by day against the previous period,
   weekday-by-hour heatmap of speed, top apps.
6. Statistics: any range including all-time, calendar of daily speed,
   monthly volume, filters by app, keyboard and layout.
7. Apps: typing time, share, speed, change and corrections per app.
8. Keys: keyboard heatmap (usage and corrections) from the Mac ANSI layout,
   per-key error rate, finger load against touch-typing assignments, travel,
   home-row share, hand alternation, same-finger pairs, slowest and fastest
   key pairs. Finger stats are labeled as assumed assignments.
9. Records: best speed, best correction rate, longest session, per app;
   current and longest daily streak.
10. Keyboards and layouts: auto-detected keyboards and input sources, compared
    side by side.
11. Live Metrics: floating always-on-top window with speed as you type,
    opened from the main window's toolbar.
12. Settings: inactivity timeout, minimum session size, tracking mode (every
    app except a list, or only a list), menu-bar format, launch at login, and
    a Capture row with listener pauses, unreadable key events and their dates.
13. Data: CSV export, delete one app's history, delete everything.
